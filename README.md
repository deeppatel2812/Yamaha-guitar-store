# Yamaha Guitar Store

This is a front-end guitar shop website made with HTML, CSS and JavaScript. I kept the original guitar photos and product list, then added some shopping features and a layout that works on phones as well as computers.

## Run the website

1. Extract this ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` with Live Server, or open the file directly in a browser.

## Files

- `index.html` — page content and layout.
- `style.css` — colors, spacing, layout and mobile styles.
- `app.js` — search, category filters, sorting, wishlist and cart actions.
- `products.js` — the guitar product information.
- `images/` — the photos used by the website.

## Features

- Search for a guitar by name.
- Filter products by guitar type.
- Sort products by price or name.
- Add guitars to the shopping bag and change quantities.
- See the cart subtotal and remove products.
- Save or unsave products with the wishlist button.
- Use the navigation menu on smaller screens.

## A note about the checkout

This is a portfolio front-end demo. The cart works in the browser, but it does not save orders to a server or take real payments. The product list and prices are sample catalogue content. This is not an official Yamaha website.
